- When the users first uses the web application, they should receive a request for permission to access their location.

- The user can choose to grant the permission or decline.
  - If the request is granted, the app should locate where the user is automatically.
  - If the request is not granted, the user should be prompted for their manual input of their location

- The user will see a screen detailing the weather conditions.

- They will have options for actions that they can take from the main screen
  - They can choose to search a location to get its weather conditions
  - They can go to the settings page to access their settings and permissions
  - They can to the locations screen to change their location
  -

- They users should receive alerts about severe weather conditions in their areas if they have notifications allowed

- The user should be able to set their display units
- The user should be able to set their preferred display theme mode: light / dark
- The user should be able to access the weather information even while they are offline
